# A Multi-Prototype Structure Constrained Class-Incremental Method for Compound Fault Diagnosis of Rolling Bearings

## Overview

Compound faults in rolling bearings exhibit complex intra-class variations and can overlap with their constituent single-fault classes in feature space.

This repository provides the core model components for a multi-prototype structure-constrained class-incremental method for compound fault diagnosis of rolling bearings.

The method uses multi-prototype representations to capture intra-class variations and local discrimination to distinguish highly correlated fault classes while learning new fault categories incrementally.

- **Multi-prototype representation**
- **Prototype-based structural constraints**
- **Local discriminative classification**

The complete training pipeline and experimental datasets are not included in this repository.

## Requirements

- Python 3.9 or later
- PyTorch
